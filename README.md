Welcome to the Design Diva's Stokvel Management Platform. This is a web-based 
application that allows payments to be made and tracked,meetings to be schedules, 
reports to be compliled and savings to be projected.

Here is how to run the app locally : 

Step 1 : Clone the repo
  https://github.com/AnovuyoJ/stokvel-project.git

Step 2 : Install backend dependencies
  cd server
  npm install

Step 3 : Install frontend dependencies
  cd client
  npm install

Step 4 : Set up environment variables
  Create a file called .env inside the server/ folder 

  Create a file called .env inside the client folder


Step 5 : Start the backend server
  cd server
  node index.js

Step 6 : Start the frontend server in a new terminal
  cd client
  npm run dev

Step 7 : Access the application
  Open your browser and go to http://localhost:5173
